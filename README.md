# Agro Business

Agro Business est une application mobile développée avec Flutter et Dart, destinée à faciliter la gestion et les activités liées au secteur agricole.

L'application a été réalisée dans le cadre d'un projet universitaire.

---

## Présentation

Agro Business est une application mobile développée avec Flutter.

L'objectif du projet est de proposer une solution mobile simple et accessible pour accompagner les utilisateurs dans leurs activités agricoles.

---

## Objectifs du projet

- Faciliter la gestion des activités agricoles
- Centraliser les informations importantes
- Proposer une interface mobile simple et intuitive
- Permettre une utilisation pratique sur smartphone
- Mettre en pratique les connaissances en développement mobile

---

## Installation

### 1. Cloner le projet

git clone https://github.com/sergio526Hal/projetagro.git

### 2. Accéder au projet

cd projetagro

### 3. Installer les dépendances

flutter pub get

### 4. Vérifier Flutter

flutter doctor

### 5. Lancer l'application

flutter run

---

## Générer l'APK

Pour générer l'APK :

flutter build apk --release

L'APK se trouve dans :

build/app/outputs/flutter-apk/app-release.apk
